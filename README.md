# aadishop

aadishop is a simple, responsive storefront demo for browsing budget-friendly fashion, home, beauty, and kids' products. It is built with plain HTML, CSS, and JavaScript and does not require a build step or backend.

## Features

- Browse products across categories
- Search products by name or category
- Add products to a cart and view the current item count
- Responsive storefront layout
- Accessible labels and live status messages

## Run locally

No dependencies or installation are required. Open `index.html` in a browser, or serve the project directory with a local static server (for example, the VS Code Live Server extension).

## Project files

- `index.html` — storefront page structure
- `styles.css` — layout and styling
- `script.js` — sample product data, search, category filtering, and cart interactions

## Notes

This is a front-end demo: product data is defined in `script.js`, and cart contents are kept in memory, so they reset when the page is refreshed. It does not process real orders or payments.
